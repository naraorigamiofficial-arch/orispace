# ORISPACE

Original origami designs, credited to their creators, with everything you need to fold them.

## Run it locally

1. Copy `.env.example` to `.env` and fill in the values.
2. `npm install`
3. `npm run db:migrate` then `npm run db:seed`
4. `npm run dev` and open http://localhost:3000

Without a `RESEND_API_KEY`, emails (confirm email, reset password) are printed in the terminal.
